# 서커스(엠씨몽 노래아님)

벙참 멤버 한 명을 사자에 태우고 불항아리와 불붙은 링을 넘으며 끝없이 달리는 서커스 게임입니다.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

1. 시작 화면에서 사자 탈 사람을 골라요: 용왕, 묭라닥, 햇살, 만두, 고란, 비노, 여니, 준탁.
2. **탭**(모바일) 또는 **스페이스 / ↑**(PC)로 점프. 아주 짧게 누르면 낮게 뜁니다.
3. 불항아리는 넘고, 불링은 사이로 통과해요. 링 안에 매달린 돈주머니는 점프 꼭대기에서 낚아채요.

- 목숨 3개. 부딪히면 하나 줄고 잠깐 무적이 돼요. 다 잃으면 공연 끝.
- 스테이지 없이 무한 질주. 달릴수록 빨라지고, 최고 속도는 시작 속도의 130%예요.
- 300점마다 장애물 등장 루틴(묘기)이 무작위로 바뀌어요. 같은 묘기는 연달아 나오지 않고, 지금 묘기 이름은 점수 아래에 떠요.

| 묘기 | 나오는 방식 |
|---|---|
| 기본 공연 | 불항아리와 불링이 섞여서 |
| 불항아리 행진 | 항아리 위주, 간격이 짧아지기도 하고 속도가 붙으면 쌍항아리 |
| 불링 쇼 | 불링만, 돈주머니 자주 |
| 다가오는 링 | 스스로 달려오는 링 |
| 링+항아리 콤보 | 링 바로 아래에 항아리 |
| 리듬 박자 | 항아리·링이 일정한 박자로 번갈아 |
| 엇박 두 번 뛰기 | 짧은 간격 두 개 뒤에 긴 숨 고르기 |
| 돈주머니 잔치 | 모든 링에 돈주머니 |
- 점수 = 달린 거리(m) + 불항아리 100 + 불링 200 + 돈주머니 500.
- `Esc`/`P` 또는 오른쪽 위 버튼으로 일시정지, 소리 끄기.
- 폰은 가로로 돌리면 앞이 더 멀리 보여요.

## 공유 랭킹 연결

게임이 끝나면 닉네임을 넣고 `등록`을 누르면 기록이 올라가요. 랭킹에는 닉네임마다 최고 기록 하나와 탔던 캐릭터가 보입니다.

공유 랭킹은 구글 시트에 저장됩니다. `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣으면 모두가 같은 랭킹을 봅니다. 주소가 비어 있거나 연결이 안 되면 플레이한 브라우저에만 저장됩니다.

서버는 점수가 `거리 + 항아리×100 + 링×200 + 주머니×500`과 정확히 맞고, 거리에 비해 장애물 수가 말이 될 때만 기록을 받아요.

## 만든 방식

- 캔버스 하나에 120Hz 고정 물리 + 보간 렌더링이라 기기 주사율과 상관없이 점프가 일정하고 부드러워요.
- 배경(천막, 관중석, 펜스, 톱밥 바닥)과 불꽃은 화면 크기에 맞춰 한 번 그려 두고 매 프레임 이어 붙이기만 해요.
- 사자는 다리 관절 각도로 매 프레임 그려서 달리기와 도약 자세가 자연스럽게 이어져요.
- 캐릭터는 원본 그림에서 배경을 지우고(누끼) 사자 등의 안장 위에 앉혀 합성했어요. 안장 담요가 몸 아랫부분을 덮어 실제로 올라탄 것처럼 보여요.
- 소리는 모두 브라우저에서 합성한 효과음과 오리지널 행진곡 루프예요.

## 파일

- `index.html` 게임 전체 (캐릭터 그림 포함, 단일 파일)
- `ranking-apps-script.gs` 공유 랭킹 서버 코드 (구글 시트용)
- `characters/` 누끼 딴 캐릭터 PNG 8장
