# 이거 뭘 그린거야 도대체!

그림으로 하는 말 전달 게임(텔레스트레이션 방식)이에요. 온라인 대결만 있고 봇은 없어요. 2~8명이 모이면 바로 시작할 수 있어요.

## 흐름

1. **닉네임**: 처음 들어오면 닉네임(2~8자)을 적어요. 이 기기에 기억되고, 로비에서 바꿀 수 있어요.
2. **로비**: 방 만들기 · 방 코드(영어 4자리)로 입장 · '지금 모이는 방' 목록에서 바로 입장 · 명예의 전당.
   - 방 만들기: **방 제목**(20자, 비우면 '닉네임의 방')과 **공개방 / 비공개방**을 골라요. 비공개방은 목록에 안 나오고 코드·초대 링크로만 들어와요.
   - 지금 모이는 방 목록: 제목 · 코드 · 방장 · 인원. 게임이 시작된 방은 빨간 굵은 글씨 **게임중**, 8명이 찬 방은 파란 굵은 글씨 **8마슨**으로 보여요 (둘 다 눌러도 못 들어가요).
   - 방장이 나가거나 끊겨도 남은 사람이 방장을 이어받아서 목록에 계속 남아요. 방에 아무도 없으면 70초 뒤 빠져요.
3. **대기실**: 초대 링크·코드 복사. 방장이 그리기 시간(40/60/90초)과 맞히기 시간(20/30/45초)을 정하고, 2명 이상이면 시작해요.
4. **단어 카드**: 각자 뒤집힌 카드 6장 중 하나를 골라요. 뒤집혀서 나온 단어가 내 스케치북의 제시어예요. 20초 안에 안 고르면 아무 카드나 골라져요.
5. **그리기 → 맞히기 → 그리기 …**: 1단계는 내 단어를 내가 그리고, 스케치북이 한 칸씩 옆 사람에게 넘어가요. 홀수 단계는 그리기, 짝수 단계는 맞히기. 단계 수 = 인원수예요.
   - 모두 내면 바로 다음 단계로 넘어가요. 시간이 끝나면 그린 데까지(빈 그림이면 빈칸)·적은 데까지(없으면 ???) 자동으로 내요.
   - 앞 사람이 비웠으면 그 전 그림·답을 대신 보여줘요.
6. **스케치북 공개**: 스케치북마다 한 장씩 넘기거나 끝까지 볼 수 있어요. 마지막에 처음 단어 ➜ 마지막 답을 보여줘요. 방장은 '한 판 더'로 같은 방에서 다시 할 수 있어요.

## 채팅

- **로비 수다방**: 로비 맨 아래. 접속한 모든 사람이 같이 써요 (같이 할 사람 구하기).
- **방 채팅**: 대기실 아래에 붙어 있고, 게임 중·스케치북 공개 중에는 오른쪽 아래 💬 버튼으로 열어요. 안 읽은 수가 배지로 뜨고, 새 메시지는 버튼 위에 잠깐 미리 보여줘요.
- 한 번에 80자, 0.7초에 한 번까지. 빠른 답장 버튼(ㅋㅋㅋ…, 마 도랏나, 마 자나, 머하는데, 째깍슨…, 이게 뭐고)이 있어요. 최근 60개만 보여주고 오래된 건 지워요.
- 저장: `rooms/doodle-chat`(로비) · `rooms/doodle-rc-<방코드>`(방)

## 명예의 전당

- 끝난 게임의 스케치북은 모두 명예의 전당에 남아요 (그림이 하나도 없는 스케치북은 빼요).
- 누구나 볼 수 있고, 재밌는 스케치북에 ❤️ 좋아요를 누를 수 있어요 (다시 누르면 취소, 내 스케치북은 못 눌러요).
- 탭: 👑 랭킹(좋아요 많은 순, 1~3등 메달) · 🆕 최신 · 🙋 내 게임.
- 스케치북 화면에서 같은 판의 다른 스케치북으로 넘어갈 수 있고, 🔗 공유로 링크(`?book=<id>`)를 복사할 수 있어요.

## 연결이 끊겼을 때

- 새로고침하거나 잠깐 끊겨도 15초 안에 돌아오면 그대로 이어서 해요.
- 15초가 지나면 나간 사람으로 보고 그 사람을 기다리지 않아요. 방장이 나가면 가장 먼저 들어온 사람이 방장이 돼요.

## 저장 (Firebase)

손모가지 조심!·사천성 가봤니?와 같은 Realtime Database를 쓰고, 규칙에서 열려 있는 `rooms/` 아래에 `doodle-` 이름으로 저장해요. **규칙은 바꿀 필요 없어요.**

- `rooms/doodle-r-<방코드>` → 방, 참가자, 진행 중인 게임(순서·카드·제시어·단계·제출 표시)
- `rooms/doodle-open/<방코드>` → 지금 모이는 방 목록 (방장이 20초마다 갱신)
- `rooms/doodle-pg-<게임id>/<주인 pid>/<단계>` → 스케치북 페이지 (그림은 480×360 webp/jpg)
- `rooms/doodle-hof/<스케치북 id>` → 명예의 전당 목록 · `rooms/doodle-thumb/<id>` 미리보기 · `rooms/doodle-like/<id>/<pid>` 좋아요

주소 뒤에 `?local=1`을 붙이면 Firebase 없이 이 브라우저에만 저장해서 시험해 볼 수 있어요 (같은 브라우저 탭끼리 대결 가능).

## 제시어

- `words.js`에 23개 묶음, 1,488개가 있어요. 한 줄이 한 묶음이고 `묶음이름: 단어, 단어, ...`처럼 쉼표로 구분해요 (띄어쓰기 있는 단어도 돼요).
- 카드 6장은 서로 다른 묶음에서 한 장씩 골라요. 카드 앞면 아래에 묶음 이름이 작게 나와요.
- 최근에 나온 단어는 한동안 덜 나와요. 단어마다 마지막으로 나온 때를 `rooms/doodle-recent/<단어>`에 적어 두고, 각 묶음에서 가장 오래 안 나온 35% 안에서만 골라요. (4명이 40판 해도 겹치는 카드는 3% 정도)
- 단어를 고친 뒤에는 `index.html`의 `words.js?v=` 숫자를 바꿔 주면 휴대폰에 바로 반영돼요.
