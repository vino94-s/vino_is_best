# 수염은 스타벅스만 잡아

구멍에서 스타벅스 컵이 올라오면 잡고, 사이사이 섞여 나오는 방해꾼은 피하는 무한 두더지게임입니다.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

- **컵:** 탭해서 잡으면 +10점. 연속으로 잡으면 콤보가 표시돼요.
- **방해꾼:** 9종의 캐릭터가 섞여 나와요. 잘못 치면 목숨이 하나 줄어요.
- 목숨 3개, 시간 제한과 단계 없음. 목숨이 다 떨어지면 게임 오버.
- 250점마다 속도 5%씩 증가, 1500점에서 130%로 고정.
- 1500점부터 방해꾼 등장률이 25% → 30%로 오르고, 250점마다 5%씩 올라 최대 45%.
- 키보드: 숫자패드 1–9로도 칠 수 있어요.
- 화면 스크롤 없이 한 화면에 고정되고, 랭킹은 오른쪽 위 `랭킹` 버튼으로 열어요.

## 공유 랭킹 연결

게임이 끝나면 닉네임을 넣고 `랭킹 등록`을 누르면 기록이 올라가요. 랭킹에는 닉네임마다 최고 기록 하나만 보입니다.

공유 랭킹은 구글 시트에 저장됩니다. `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣으면 모두가 같은 랭킹을 봅니다. 주소가 비어 있거나 연결이 안 되면 플레이한 브라우저에만 저장됩니다.

서버는 점수가 `잡은 컵 수 × 10`과 정확히 맞을 때만 기록을 받아요.

## 파일

- `index.html` 게임 전체 (컵 사진과 방해꾼 그림 포함, 단일 파일)
- `ranking-apps-script.gs` 공유 랭킹 서버 코드 (구글 시트용)
