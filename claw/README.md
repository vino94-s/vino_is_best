# 술안먹고 뽑을수있지?

벙참 공용 캐릭터 13명으로 채운 오락실 뽑기예요. 인형뽑기 옆에 키캡·키링·클리커 뽑기 기계도 있어요. 혼자 기록에 도전하거나, 방 코드로 친구 최대 4명과 누가 더 많이 뽑나 대결해요.

## 플레이

1. **처음 왔어요**에서 닉네임과 캐릭터를 고르면 6자리 **입장 코드**가 나와요. 다음부터는 이 코드로 들어와요.
2. **🎟 충전**에서 크레딧을 사요. 잡기 한 번에 크레딧 1회가 써져요.
   - 1회 1,000원 · 6회 5,000원 · 13회 10,000원
3. 로비의 **오락실 기계 고르기**에서 기계를 고르고 **혼자 뽑기** 또는 **방 만들기 / 코드로 입장**.
4. 타이머는 **20초**이고, **잡기를 누를 때마다 다시 20초로 채워져요.** 시간이 다 떨어지면 판이 끝나요. 화면을 드래그하면 집게가 움직여요(좌우 = 좌우, 위아래 = 안쪽/바깥쪽). 바닥의 파란 원이 집게가 내려갈 자리예요.
   - **조준 가이드**: 집게에서 레이저가 내려가 과녁을 찍고, 잡힐 인형 위에 화살표와 안내가 떠요. 과녁 색으로 잡히기 쉬운지 알려줘요.
     🟢 정중앙(지금 잡아요) · 🟡 조금 옆 · 🟠 가장자리 / 다른 인형에 깔림 · ⚪ 빈자리 / 구멍 위
   - 바닥의 점선 십자선과 앞·왼쪽 가장자리의 작은 화살표가 집게의 좌우·앞뒤 위치를 보여줘요.
5. **잡기!**를 누르면 집게가 내려가서 잡고, 왼쪽 앞 구멍까지 옮겨서 떨어뜨려요. 구멍에 들어가면 1개 획득.
6. PC에서는 방향키로 움직이고 스페이스로 잡기, H로 기계 때리기.

## 기계 때리기

- 인형을 놓치거나 헛손질하면 **👊 기계 때리기** 버튼이 켜져요.
- 때리면 기계가 흔들려서 구멍 근처 인형이 굴러 들어갈 수도 있어요.
- **2번까지는 괜찮아요.** 버튼 아래 ●○로 사장님 화난 정도가 보여요.
- **3번째로 때리면 사장님(용왕)에게 쫓겨나서 2분 동안 게임을 못 해요.** 판도 그 자리에서 끝나요. 쫓겨나면 횟수는 0부터 다시 세요.

## 기계 4대

| 기계 | 상품 | 크기·개수 | 특징 | 판매가 |
|---|---|---|---|---|
| 🧸 인형뽑기 | 폭신한 인형 | 크게 21개 | 기본 | 아래 표 그대로 |
| ⌨️ 키캡뽑기 | 얼굴이 인쇄된 키캡 | 작게 30개 | 잡기 조금 쉽지만 잘 미끄러져요 | ×0.6 |
| 🔑 키링뽑기 | 아크릴 키링 | 작게 27개 | 고리가 걸려서 잘 잡혀요 | ×0.7 |
| 🖲️ 클리커뽑기 | 얼굴 버튼 클리커 | 작게 27개 | 뽑으면 딸깍딸깍 소리 | ×0.75 |

크레딧과 게임머니는 네 기계가 같이 써요. 대결 방에서는 방장이 기계를 골라요.

### 히든 인형 '히든용왕'

- 인형뽑기 기계에 깔리는 인형 하나하나가 **0.5%** 확률로 히든용왕이 돼요. 한 판에 21개가 깔리니 대략 10판에 한 번꼴로 기계 안에 나타나요.
- 나타나면 판이 시작될 때 "…기계 안에서 뭔가 반짝인다?!" 알림이 뜨고, 기계 안에서 무지개색으로 반짝여요.
- 샵 인형 도감에 **?** 칸으로 숨어 있다가, 뽑으면 그림이 열려요.
- 그림은 `special-yongwang.png`(배경을 지운 인형 사진)예요.

- 난이도는 처음 버전보다 10% 쉬워졌어요 (잡히는 확률 ×1.1, 미끄러지는 확률 ×0.9).
- 판마다 기계에 상품이 새로 깔려요. 위에 다른 인형이 얹혀 있으면 잘 안 잡혀요. 집게 가운데로 잡을수록 잘 잡혀요.
- 비싼 인형일수록 올라가다가 잘 미끄러져요. 미끄러진 인형이 구멍 위로 떨어지면 그것도 획득이에요.
- 뽑은 상품은 **🛍 샵**에서 종류별 탭(인형·키캡·키링·클리커)으로 팔아 게임머니로 바꿀 수 있어요. 종류마다 도감(13종)도 있어요.

## 🧪 합성소 (인형 컬렉션 51종)

로비의 **🧪 합성**에서 인형 2개를 합쳐 새 인형을 만들어요. 컬렉션은 기본 14종(히든 포함) + 합성 37종 = **51종**이에요.

- **성공 확률 60%** 고정. 실패하면 재료 2개 중 1개(무작위)가 사라지고 1개는 돌려받아요.
- 레시피는 정해져 있어요. 재료는 보이지만, 결과 인형은 처음 만들기 전까지 실루엣과 ???로 가려져요.
- **1세대 24종**: 기본 인형 + 기본 인형 (반짝이 표시)
- **2세대 10종**: 합성 인형이 재료 (왕관 표시). '따봉대제'는 히든 '히든용왕'이 있어야 만들 수 있어요.
- **3세대 3종**: 최종 합성 (왕관 + 무지개 오라). 최종 보스는 '바다의 지배자'.
- 합성 인형은 바탕 캐릭터 얼굴에 다른 캐릭터의 특징을 합친 새 인형이에요. 부품은 원본 그림에서 오려 써요: 용왕 왕관·수염, 준탁 모자·장미, 햇살 꽃잎 후광, 묭라닥 볏, 영준(머리 위 새), 고란 토끼귀, 만두 고양이귀, 봉춤 치와와귀, 여니 강아지귀, 엄지 따봉 손. 몸통 색도 섞여요. 세대가 오를수록 조상 특징이 더 붙고, 2세대는 금별, 3세대는 무지개 오라가 붙어요. 생김새는 `index.html`의 `FUSE_LOOK`에서 바꿔요.
- 직접 그린 합성 인형 그림은 `fusion/<id>.png`(배경 없는 PNG)에 두고 `index.html`의 `FUSE_ART` 목록에 id를 넣으면 그 그림을 그대로 써요. 지금은 37종 모두(f01~f24, g01~g10, h01~h03) 직접 그린 그림이에요.
- **다른 조합 35개**: 인형마다 다른 재료 조합이 딱 하나씩 더 있어요(결과 중복 없음, 레시피 총 72개). 따봉대제와 바다의 지배자는 원래 조합만 있어요.
- 판매가는 그 인형을 만드는 **가장 싼 조합**의 재료 판매가 합 × 1.5(1세대) / 1.6(2세대) / 1.8(3세대). 싼 재료로 만들어 비싸게 되파는 꼼수를 막으려고요. 샵 인형 탭에서 팔 수 있어요.
- 컬렉션은 한 번이라도 가져 본 인형으로 세요. 팔거나 합성에 써도 컬렉션에서 안 빠져요.
- '지금 만들 수 있는 것만'을 누르면 재료가 다 있는 레시피만 보여요.
- 랭킹 **📖 컬렉션** 탭에서 누가 많이 모았는지 볼 수 있어요.
- 확률과 레시피는 `index.html`의 `FUSE_RATE`, `FUSE_LIST`(기본 조합), `ALT_RECIPES`(다른 조합)에서 바꿔요.

- **방 만들기**를 누르면 5자리 방 코드가 나와요. **초대 링크 복사 / 공유하기**로 보내세요.

## 어드민

로그인 화면이나 로비의 **어드민 접속하기**에서 비밀번호로 들어가요 (코드에는 비밀번호 대신 SHA-256 해시만 들어 있어요).

- 목록은 보유자산이 적은 순 (0원인 유저가 맨 위), 같으면 최근 가입 순
- 🔍 닉네임 검색 (글자 일부만 넣어도 찾아요)
- **일괄 충전·빼기**: 돈(원)·크레딧(회)을 넣고 **모든 유저** 또는 **검색된 유저만** 골라 ➕ 충전 / ➖ 빼기. 적용 전에 대상 인원과 금액을 한 번 더 확인해요. 빼기는 0 아래로 내려가지 않아요.
- 유저별 **바로 충전** 버튼: +2만원 · +5만원 · +10만원 (누르면 바로 들어가요)
- 유저별 💰 직접 입력 / 🎟 크레딧 주기·빼기 (음수 입력하면 빼기)
- 🔑 새 코드 발급 (코드를 잃어버린 사람용. 예전 코드도 계속 쓸 수 있어요)
- 🚫 쫓겨남 해제 + 때린 횟수 초기화
- 플레이어 삭제

입장 코드는 목록으로 볼 수 없게 저장돼서, 어드민도 기존 코드를 볼 수는 없어요.

## 데이터 (Firebase)

손모가지 조심!(`gostop/`)과 같은 Firebase Realtime Database(`gostop-7c4a2`)를 써요. 따로 규칙을 올리지 않아도 되도록, 지금 규칙에서 읽기·쓰기가 열려 있는 `rooms/` 아래에 `claw2-` 이름으로 저장해요.

### 2026-10-22 회원 리셋

- 오류: 접속할 때 계정 정보를 받기 전에 계정을 고치는 작업이 먼저 돌면서, Firebase가 잠깐 보낸 빈 값(null)을 '계정 삭제'로 오인해 로그아웃시켰어요. 새로 가입해도 같은 일이 생겼어요.
- 고친 점: 트랜잭션 중간값을 화면에 보내지 않고(`applyLocally=false`), 첫 서버 값을 받은 뒤에만 계정을 고치고, 빈 값이 오면 서버에 다시 확인해서 정말 없을 때만 로그아웃해요.
- 리셋: 새 시즌 데이터는 `rooms/claw2-*`에 저장해요. 예전 데이터(`rooms/claw-*`)는 지우지 않고 보관해요.
- 예전 코드로 들어오면 리셋 안내가 떠요. **예전과 같은 닉네임**으로 다시 가입하면 인형·키캡·키링·클리커와 컬렉션을 그대로 돌려줘요 (돈·크레딧·전적은 새로 시작, 대신 100,000원 지급).

| 경로 | 내용 |
|---|---|
| `rooms/claw2-players/{pid}` | 닉네임, 캐릭터, 돈, 크레딧, 인형(`dolls`), 키캡·키링·클리커(`goods`), 전적, 때린 횟수, 쫓겨난 시각 |
| `rooms/claw2-nicks/{닉네임}` | 닉네임 중복 확인 |
| `rooms/claw2-acc-{코드}` | 입장 코드 → pid (코드마다 따로 있어서 목록 조회 불가) |
| `rooms/claw2-r-{방코드}` | 대결 방 |
| `rooms/claw2-matches` | 최근 대결 30판 |
| `rooms/claw2-log` | 어드민 작업 기록 |

나중에 전용 경로로 옮기고 싶으면 `index.html`의 `CFG.prefix`를 바꾸고, `gostop/database.rules.json`에 그 경로 규칙을 추가해 Firebase 콘솔에 게시하세요.

Firebase에 연결하지 못하면 자동으로 **오프라인 모드**(이 브라우저에만 저장)로 돌아가요. 주소 끝에 `?local=1`을 붙이면 일부러 오프라인 모드로 열 수 있어요(테스트용).

서버 없이 브라우저가 DB에 직접 쓰는 구조라 친구끼리 노는 용도로 쓰세요.

## 바꾸기 쉬운 값

`index.html` 위쪽 `CFG`, `TIERS`, `MACH`, `EASY`:

- `daily`, `startMoney` 매일 충전 금액·가입 금액
- `packs` 크레딧 가격표
- `roundSec` 한 판 시간, `freeHits` 봐주는 때리기 횟수, `banSec` 쫓겨나는 시간
- `EASY` 전체 난이도 배율, `MACH` 기계별 크기·개수·잡기·미끄러짐·판매가 배율
- `TIERS`의 `price`(판매가), `grip`(잡히는 정도), `slip`(미끄러지는 정도), `w`(나오는 비율)
