# 대환장 바둑벙

묭라닥, 따봉, 만두, 고란, 여니, 준탁, 햇살, 비노, 영준, 용왕. 열 명의 얼굴이 바둑알이 됐습니다. 알을 골라 알까기나 오목으로 붙어 보세요.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

1. 게임 고르기: **알까기** 또는 **오목**
2. 상대 고르기: **봇 대결** 또는 **친구 대결** (초대코드로 각자 휴대폰에서 원격 대결)
3. 바둑알 고르기: 알을 누르면 그 캐릭터의 효과음과 대사가 나와요.

- **알까기:** 내 알을 잡고 뒤로 당겼다 놓으면 반대 방향으로 날아갑니다. 상대 알을 모두 판 밖으로 밀어내면 승리.
- **오목:** 둘 자리를 한 번 누르면 미리보기, 같은 자리를 한 번 더 누르면 착수. 다섯 알을 먼저 한 줄로 이으면 승리.

## 친구 대결 (초대코드)

1. 한 명이 **방 만들기**를 누르면 4자리 초대코드가 나와요. **초대 복사**로 코드와 링크를 친구에게 보내세요.
2. 친구는 **초대코드로 입장**에 코드를 넣거나, 받은 링크를 열면 바로 같은 방에 들어와요.
3. 대기실에서 각자 바둑알을 고르고(서로 다른 알) 둘 다 **준비 완료**를 누르면 시작해요.

- 게임 종류(알까기·오목)는 방장이 고른 쪽으로 정해져요.
- 알까기는 각자 화면에서 내 알이 항상 아래쪽에 보여요.
- 판마다 먼저 두는 사람이 번갈아 바뀌어요.
- 연결은 PeerJS로 브라우저끼리 직접 이어져요. 친구가 나가면 방장은 같은 코드로 다시 기다릴 수 있어요.

## 봇 20단계

5단계마다 봇의 급수가 올라갑니다: 입문(1–5) → 중수(6–10) → 고수(11–15) → 국수(16–20). 같은 급수 안에서도 단계가 오를수록 실수가 줄어요. 5·10·15·20단계는 보스전이고, 오목은 16단계부터 봇이 먼저 둡니다.

## 캐릭터별 효과

알끼리 부딪칠 때와 판에 알을 둘 때 캐릭터마다 다른 효과와 소리가 나요.

| 캐릭터 | 효과 |
|---|---|
| 묭라닥 | 깃털이 흩날리고 "꼬끼오!" |
| 따봉 | 금색 별이 터지고 "따봉!" |
| 만두 | 김이 모락모락 "말랑~" |
| 고란 | 콧물 방울이 튀고 "주르륵" |
| 여니 | 땀방울과 먼지 "끄응.." |
| 준탁 | 느낌표 폭발, 화면 흔들림 |
| 햇살 | 햇살이 퍼지며 "안물안궁" |
| 비노 | 흑백 충격파 "..." |
| 영준 | 색종이 폭죽 "짹짹!" |
| 용왕 | 물결과 금빛 반짝이 "에헴" |

## 공유 랭킹 연결

봇 대결 랭킹(최고 단계 순)과 친구 대결 랭킹(이름별 승수 합산)이 알까기·오목 따로 있습니다.

공유 랭킹은 구글 시트에 저장됩니다. `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣으면 모두가 같은 랭킹을 봅니다. 주소가 비어 있거나 연결이 안 되면 플레이한 브라우저에만 저장됩니다.

## 파일

- `index.html` 게임 전체 (바둑알 그림 포함, 단일 파일)
- `*.png` 캐릭터 바둑알 그림 원본
- `ranking-apps-script.gs` 공유 랭킹 서버 코드 (구글 시트용)
