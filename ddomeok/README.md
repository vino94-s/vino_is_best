# 엄지는 또머글꺼얌

포장마차 천막 아래로 안주와 술이 쏟아집니다. 엄지 맨 윗마디를 좌우로 까딱여 음식은 왼쪽 접시로, 술은 오른쪽 술 짝으로 튕기고, 중간중간 떨어지는 파리는 엄지로 꾹 눌러 잡는 게임입니다.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

- **음식:** 화면 왼쪽 터치 또는 ← 키
- **술:** 화면 오른쪽 터치 또는 → 키
- **파리:** 엄지를 터치 또는 ↑ 키 (스페이스바도 가능)
- 점선 아래로 내려온 것만 처리할 수 있어요. 가장 아래에 있는 것부터 처리됩니다.
- 음식·술 10점, 파리 20점. 5개 연속 성공마다 점수 배율이 올라가요 (최대 5배).
- 목숨 3개. 방향을 틀리거나, 놓치거나, 파리가 엄지에 앉으면 하나씩 줄어요.
- 점수가 오를수록 더 빨리, 더 자주 떨어지고 파리도 늘어납니다.

## 공유 랭킹 연결

시작 화면에서 닉네임을 정하면, 게임이 끝날 때 내 최고 기록을 넘은 경우에만 자동으로 랭킹에 올라갑니다.

공유 랭킹은 구글 시트에 저장됩니다. `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣으면 모두가 같은 랭킹을 봅니다. 주소가 비어 있거나 연결이 안 되면 플레이한 브라우저에만 저장됩니다.

## 파일

- `index.html` 게임 전체 (그림 포함, 단일 파일)
- `thumb.png` 원본 엄지 그림 (배경 제거)
- `ranking-apps-script.gs` 공유 랭킹 서버 코드 (구글 시트용)
