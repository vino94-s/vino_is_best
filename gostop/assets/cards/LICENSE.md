# 화투 그림 저작권

이 폴더의 카드 그림은 [Louie Mantia](https://commons.wikimedia.org/wiki/User:Louiemantia)가 그린 하나후다 그림(위키미디어 공용)을 바탕으로 했고,
[크리에이티브 커먼즈 저작자표시-동일조건변경허락 4.0 국제 라이선스(CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.ko)를 따릅니다.

한국 화투에 맞게 고친 내용:

- 11월(오동)과 12월(비)을 화투 순서로 바꿔 배치
- 홍단 띠의 일본어 글귀를 지우고 '홍단', 청단 띠에 '청단' 글씨 추가
- 광 다섯 장에 光 표시 추가
- 보너스 쌍피·쓰리피 카드(`B2`, `B3`) 새로 그림

고친 그림도 같은 CC BY-SA 4.0 라이선스로 배포합니다.
