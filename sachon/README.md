# 사천성 가봤니?

인형뽑기(술안먹고 뽑을수있지?) 기계의 기본 인형 16종으로 하는 사천성(같은 그림 맞추기)이에요. 한 판(보드)을 모두 같이 보면서 봇·친구 최대 4명이 **동시에** 60초 동안 맞추고, 가장 많은 쌍을 지운 사람이 판돈을 전부 가져가요.

## 규칙

- 같은 그림 두 개를 차례로 누르면, **꺾이는 곳이 2번 이하**인 선으로 이어질 때 지워져요. 선은 판 바깥 테두리로도 지나가요.
- 모두 같은 판에서 맞춰요. 두 사람이 같은 패를 누르면 서버에 먼저 도착한 사람이 가져가요(늦은 사람은 "앗, 한발 늦었어요!").
- 판이 다 지워지면 다른 모양의 새 판이 바로 이어져요. 이어지는 쌍이 하나도 없으면 남은 패를 자동으로 섞어요.
- 60초가 지나면 끝. 1위가 둘 이상이면 판돈을 나눠 갖고, 모두 0쌍이면 판돈을 돌려줘요.
- 시간은 모두 똑같이 60초예요. '햇살 연장전'을 쓴 사람만 시간이 늘어나요. 먼저 끝난 사람은 **게임 종료 · 관전 화면**으로 바뀌어서, 연장한 사람이 계속 맞추는 모습(선·지워지는 패·남은 시간·점수)을 지켜봐요. 연장한 사람까지 끝나면 결과가 나와요.

## 패 (16종)

엄지 · 여니 · 영준 · 용왕 · 준탁 · 햇살 · 고란 · 깨굴 · 만두 · 묭라닥 · 봉춤 · 비노 · 가나 + 현꿀오소리 · 헤존구 · 별나라.
그림은 `claw/plush/<id>.png`(실제 인형 사진)를 120px WebP로 줄인 `img/<id>.webp`예요. 비슷한 하얀 인형도 구분되게 종류마다 패 바탕색이 달라요.

## 돈 · 판돈

- 가입하면 100,000원 + 엄지 따봉 힌트 1개. 자동 충전은 없고, 운영자가 어드민에서 넣어 줘요.
- 판돈: 1만 · 3만 · 5만 · 10만원. 시작할 때 모두에게서 걷고, 이긴 사람이 전부(봇 몫 포함) 가져가요.
  - 봇이랑 대결: 봇 1~3명, 실력 쉬움/보통/어려움. 봇 몫은 가게 돈이에요.
  - 대결 방: 방장이 판돈·봇 수·봇 실력을 정해요. 시작 전에 모두의 돈이 판돈보다 많은지 확인해요.
- 돈이 오가는 일(판돈 걷기, 상금 주기)은 key로 한 번만 처리돼서 두 번 처리되지 않아요.

## 상점 아이템

| 아이템 | 효과 | 값 | 한 판에 |
|---|---|---|---|
| 📜 용왕의 어명 | 같은 그림 한 쌍을 바로 지우고 +1쌍 | 9,000원 | 3번 |
| 🍫 가나의 초코 범벅 | 다른 사람 화면을 3초 동안 가림 | 6,000원 | 3번 |
| ☀️ 햇살 연장전 | 내 시간만 +10초 | 4,500원 | 2번 |
| 👍 엄지 따봉 힌트 | 이어지는 한 쌍을 3초 동안 반짝 | 2,000원 | 5번 |

값과 횟수는 `index.html`의 `ITEMS`에서 바꿔요.

## 어드민

로그인 화면의 **🔐 어드민** → 비밀번호. 플레이어마다 돈 넣기·빼기, 아이템 넣기·빼기, 새 코드 발급(예전 코드는 바로 막혀요), 코드 정지·다시 켜기. 위쪽에서 모두에게 일괄로 돈을 넣고 뺄 수 있어요. 한 일은 `rooms/sachon-log`에 남아요.

## 저장 (Firebase)

손모가지 조심!과 같은 Realtime Database를 쓰고, 지금 규칙에서 열려 있는 `rooms/` 아래에 `sachon-` 이름으로 저장해요. **규칙은 바꿀 필요 없어요.**

- `rooms/sachon-nicks/<닉네임>` → pid
- `rooms/sachon-acc-<코드>` → { pid, v } (v가 플레이어의 codeV와 같아야 입장)
- `rooms/sachon-players/<pid>` → 돈, 아이템, 전적
- `rooms/sachon-r-<방코드>` → 방, 진행 중인 판(`g`: 판 문자열 · 점수 · 마지막 수), 초코 범벅(`fx`), 지난 결과(`last`)

주소 뒤에 `?local=1`을 붙이면 Firebase 없이 이 브라우저에만 저장해서 시험해 볼 수 있어요(같은 브라우저 탭끼리 대결도 돼요).

## 부드럽게 돌아가게

- 패 120개는 한 번만 만들어 두고 다시 써요. 지워질 때는 투명도·크기(transform)만 바뀌어서 GPU가 그려요.
- 선은 SVG 한 줄이 0.36초 동안 사라지는 애니메이션이에요.
- 온라인에서는 내가 맞춘 쌍을 화면에서 **먼저** 지우고 서버에서 확인해요. 서버가 거절하면 그때만 되돌려요.
- 매 프레임 하는 일은 시계 숫자와 막대 길이뿐이에요.
