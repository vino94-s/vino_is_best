# 천하제일 무술대회

비노·만두·준탁·영준·햇살·엄지·고란·용왕·묭라닭·여니, 열 고수가 겨루는 2D 격투게임입니다. 한 판 60초, 3판 2선승.

## 플레이

`index.html`을 웹에서 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

- **봇 도전 (10단계):** 캐릭터를 고르고 1단계부터 시작. 1~9단계는 열 고수 중 아홉 명이 무작위 순서로 나오고(나와 같은 캐릭터는 다른 색), 단계가 오를수록 봇이 강해져요. 10단계는 최종 보스 **소주**. 한 번 지면 도전이 끝나요
- **친구와 대결:** 방 만들기 → 4자리 초대코드(또는 초대 링크)를 친구에게 보내면 1:1 대결. 둘 다 준비 완료를 누르면 시작. 끝까지 치른 대결은 친구 대결 랭킹에 자동 기록
- 친구와 같은 캐릭터를 고르면 친구 쪽(오른편)은 다른 색으로 보여요
- 시간이 다 되면 남은 체력 비율이 높은 쪽이 그 판을 가져가요. 무승부 판이 이어지면 최대 5판까지

### 최종 보스 · 소주 (10단계, 선택 불가)

체력 136, 힘 1.1로 가장 세고, 필살 게이지가 저절로 차요. 필살기 **병뚜껑 부메랑 날리기** — 병뚜껑을 날렸다가 되돌아오게 해서 가는 길·오는 길 두 번 때려요.

때리거나 맞으면 필살 게이지가 차요.

## 랭킹

랭킹 화면은 **봇 도전**과 **친구 대결** 두 탭이에요.

### 봇 도전

봇 도전이 끝났을 때(탈락·그만두기·전 단계 클리어) 한 단계 이상 깼으면 누적 점수를 닉네임으로 등록할 수 있어요.

점수 = 깬 단계마다 [단계 점수 + 2:0 완승 보너스 50 + 남은 체력 보너스(이긴 판 평균 체력 × 100)]의 합. 단계 점수는 n단계 = 50 + 30×n (1단계 80 … 9단계 320), 10단계 보스 600.

### 친구 대결

친구 대결을 끝까지 치르면 방장 브라우저가 결과를 한 번 기록해요: 두 사람의 닉네임, 고른 캐릭터, 판 점수(예: 2:1), 이긴 사람, 날짜. 중간에 나가거나 연결이 끊긴 대결은 기록되지 않아요.

- **전적 순위:** 닉네임별 승·패·무, 승률, 가장 많이 쓴 캐릭터 (승수 → 승률 → 판수 순)
- **최근 대결:** 누가 누구와 어떤 캐릭터로 붙어 몇 대 몇이 됐는지 최근 순

로그인이 없어서 같은 닉네임은 같은 사람으로 세요. 장난 기록은 시트의 `duels` 탭에서 그 줄을 지우면 빠져요.

### 공유 랭킹 연결

공유 랭킹은 구글 시트에 저장됩니다(봇 도전은 `stage_scores` 탭, 친구 대결은 `duels` 탭). `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣으면 모두가 같은 랭킹을 봅니다. 주소가 비어 있거나 연결이 안 되면 플레이한 브라우저에만 저장됩니다.

### 카톡으로 코드 보낼 때

- 카카오톡(또는 라인) 안에서 링크를 열면 휴대폰 기본 브라우저(크롬·사파리)로 옮겨서 열어요. 카톡 안의 브라우저는 채팅방으로 돌아가는 순간 게임 화면이 닫혀서 방이 사라지기 때문이에요.
- 방장이 카톡에 코드를 보내러 다녀오는 사이 연결이 끊겨도, 돌아오면 같은 코드로 다시 이어져요. 탭이 새로고침돼도 30분 안이면 같은 방 코드로 다시 열려요.
- 방장이 아직 카톡에 가 있는 동안 친구가 먼저 링크를 열면, 1분 동안 방장을 기다렸다가 들어가요.
- 친구가 새로고침해도 같은 방에 다시 들어가요.

## 친구 대전 연결 방식

방장 브라우저가 경기를 계산하고, 친구 브라우저는 입력을 보내고 화면을 받아 그립니다. 두 브라우저는 [PeerJS](https://peerjs.com)(무료 공개 중계 서버)로 직접 연결돼요. 서버를 따로 띄울 필요는 없지만, 회사·학교 와이파이처럼 연결을 막는 네트워크에서는 접속이 안 될 수 있어요. 그럴 땐 한쪽이 휴대폰 데이터로 바꿔 보세요.

인터넷 상태에 따라 친구 쪽 화면이 아주 약간 늦게 반응할 수 있어요.
