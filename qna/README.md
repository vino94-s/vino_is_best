# 벙참 정모 Q&A

https://vino94-s.github.io/vino_is_best/qna/ · 벙참 보드 '❓정모 Q&A' 탭 안에도 들어가요 (`?embed=1`).

- 누구나 **익명**으로 질문을 올려요 (5~300자, 같은 기기에서 30초 간격). 닉네임·캐릭터는 저장하지 않아요.
- 공감하는 질문에 **❤️ 공감**을 눌러요. 질문마다 기기당 한 번, 다시 누르면 취소.
- 목록은 **공감 많은 순**(같으면 최신 순). 위 3개는 '공감 N위'로 표시. '최신순'으로도 볼 수 있어요.
- 내가 올린 질문은 '내 질문' 표시와 삭제 버튼이 보여요 (이 기기에서만).
- 아래 **운영진** 버튼 → 비밀번호(손모가지 조심! 어드민과 같음)로 들어가면 질문마다 **답변 완료**(목록 맨 아래로 내려가요)·**삭제**를 할 수 있어요.

## 데이터 (Firebase)

손모가지 조심!·수다방과 같은 Realtime Database(`gostop-7c4a2`)의 `rooms/bung-qna/q/<id>`:
`{ text, ts, likes: { <기기id>: true }, done }`. 기기 id는 이 브라우저에만 저장되는 무작위 값이라 사람과 연결되지 않아요.
