# 할린데예 갈린데예

과일 대신 캐릭터 얼굴이 그려진 할리갈리예요. 펼쳐진 카드들에서 같은 캐릭터가 합쳐서 정확히 5개 보이면 누구보다 빨리 종을 치세요.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

1. 닉네임을 넣고 **봇이랑 한 판** 또는 **친구랑 한 판**을 고르세요.
2. 내 차례가 오면 파란 카드 더미를 눌러 한 장을 뒤집어요. (Space)
3. 같은 캐릭터가 합쳐서 정확히 5개면 가운데 종을 쳐요. (Enter)

## 규칙

- 카드는 56장. 캐릭터 4명 × (1개 5장, 2개 3장, 3개 3장, 4개 2장, 5개 1장)
- 판마다 열두 캐릭터 중 4명이 카드에 나와요.
- 제일 빨리 친 사람이 깔린 카드를 전부 가져가고 다음 차례를 잡아요.
- 헛방(5개가 아닌데 침)이면 다른 사람에게 1장씩 줘요.
- 내 차례에 뒤집을 카드가 없으면 탈락이에요.
- 한 명만 남거나 3분이 지나면 끝나요. 시간이 다 되면 가진 카드(덱 + 깔린 카드)가 가장 많은 사람이 이겨요.
- 내 차례에 6초 동안 안 뒤집으면 자동으로 뒤집혀요.

## 캐릭터

왈왈이, 용왕, 엄지, 영준, 햇살, 묭라닥, 고란, 여니, 비노, 만두, 준탁, 깨굴

## 봇전

- 봇 1~3명과 개인전을 해요.
- 난이도는 쉬움 · 보통 · 어려움 세 가지예요. 어려울수록 봇이 빨리 치고 헛방이 줄어요.
- 이기면 승점 = 난이도(쉬움 1 · 보통 2 · 어려움 3) × 봇 수.

## 친구대전 (친구 코드)

1. 한 명이 **새 방 만들기**를 누르면 5자리 친구 코드가 나와요. **초대 링크 복사**로 친구에게 보내세요.
2. 친구는 **친구 코드로 참가**에 코드를 넣거나 받은 링크를 열면 같은 방에 들어와요.
3. 2명 이상이면 방장이 **게임 시작**을 눌러요. 최대 4명이 각자 개인전으로 붙고, 5번째부터는 관전해요.

방장 브라우저가 게임을 계산하고, 친구 브라우저는 뒤집기·종 치기만 보내요. 종은 각자 화면에 카드가 뜬 순간부터 잰 반응 시간으로 판정해서, 인터넷이 조금 느린 쪽도 공정하게 겨뤄요.

GitHub Pages에서는 [PeerJS](https://peerjs.com)(무료 공개 중계 서버)로 브라우저끼리 직접 연결돼요. 회사·학교 와이파이처럼 연결을 막는 네트워크에서는 접속이 안 될 수 있어요. 그럴 땐 한쪽이 휴대폰 데이터로 바꿔 보세요. claude.ai 아티팩트에서 열면 아티팩트의 방 기능으로 연결돼요.

## 오픈 랭킹

- **봇전 랭킹**: 승점, 승/판, 승률, 어려움 승리 수, 최고 반응속도
- **친구대전 랭킹**: 우승 순위와 판별 기록. 판마다 누가 참여했는지, 각자 몇 장 남았는지, 누가 이겼는지 보여줘요.

GitHub Pages에서 모두가 같은 랭킹을 보려면 `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣어 주세요. 비어 있으면 플레이한 브라우저에만 저장돼요. claude.ai 아티팩트에서는 아티팩트 공유 DB에 바로 저장돼요.

## 파일

- `index.html` 게임 전체 (캐릭터 그림 포함, 단일 파일)
- `*.jpg` 캐릭터 얼굴 그림
- `ranking-apps-script.gs` 공유 랭킹 서버 코드 (구글 시트용)
