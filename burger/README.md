# 놀러오세요, 준탁의 어메리카 버거하우스

준탁 셰프와 버거 가게를 키우는 경영 게임이에요. 120초 영업 동안 손님 주문대로 버거·피자·감자튀김·콜라·생맥주를 만들어 팔고, 번 돈으로 가게를 확장해요.

## 입장

- **처음 왔어요**: 닉네임(2~10자 · 가게 이름이 돼요) + 내 캐릭터(히든 인형 15종) → 6자리 **입장 코드** 발급. 가입 선물 $100.
- **코드로 입장**: 이 기기에 코드가 기억돼서 다음엔 바로 들어가요. 잃어버리면 어드민에서 새 코드 발급.
- 매일 한국 시간 아침 6시 이후 첫 접속 때 출근 보너스 $50.

## 영업 (120초)

1. 아래빵 → 재료 → 위빵 순서로 쟁반에 버거를 만들어요 (재료 순서는 상관없어요).
2. 패티는 그릴에서 먼저 구워야 써요. 피자는 도우 → 소스 → 모차렐라 → 토핑 → 오븐(5초) → 꺼내기.
3. 다 만들면 그 손님을 눌러서 내줘요. 맞는 주문서는 초록색으로 반짝여요. 빨리 낼수록 팁이 커요.
4. 틀리면 평점 −, 손님이 기다리다 떠나도 평점 −. 평점이 높을수록 손님이 자주 와요.
5. 손님은 인형뽑기의 **히든 인형 15종**이에요. 고란·준탁은 **✨초희귀 인형**(초희귀고란·초희귀 준탁)으로 가끔만 오고(6%) 팁 3배! 친구가 내 가게에 손님으로 오면(👫 표시) 팁 2배.
6. 번 돈은 영업이 끝나면 바로 내 돈이 돼요. ✕로 중간에 접어도 그때까지 번 돈은 챙겨요.

## 체인점 (본점부터 · 로비 🗺️)

미국 지도에서 도시를 눌러 체인점을 내요: 뉴욕 $20,000 · LA $18,000 · 라스베이거스 $16,000 · 시카고·샌프란시스코 $15,000 · 마이애미 $14,000 · 시애틀 $12,000 · 보스턴 $11,000 · 휴스턴 $10,000 · 내슈빌·뉴올리언스 $9,000 · 덴버 $8,000.

- **하루 정산**: 지점은 점장이 하루 종일 알아서 영업해요. 지점 하루 매출 ≈ 도시 기본값 × 15 × 지점 레벨 배율(±20%). 매일 **아침 6시**(영업일이 바뀔 때)에 전날 매출의 **35%**가 본점으로 정산되고, 그다음 접속 때 "📬 체인점 정산 도착!" 창이 떠요. 못 받은 정산은 7일치까지 쌓여요. 정산금은 그 날짜의 매출에 들어가요.
- 개설한 날 영업분은 다음 날 아침 첫 정산. 지점 확장 Lv.2(개설비 60%, 매출 ×1.8)·Lv.3(개설비 100%, ×2.8).
- **👀 지점 시찰**: 도시 풍경 속 지점에 손님이 오가는 모습, 오늘 지점 매출(실시간으로 올라가요), 어제 정산금, 누적 정산, 내일 아침 예상 정산.
- 보유재산에 체인점 값도 더해져요.

## 친구

- 닉네임으로 추가하거나 랭킹에서 가게를 눌러 **친구 추가** → 서로 친구가 돼요.
- **친구 가게 놀러가기**: 가게 안을 내 캐릭터로 **걸어 다녀요** — 바닥을 누르거나 방향키(◀▲▼▶, PC는 화살표 키). 가까이 가면 할 수 있는 일이 버튼으로 떠요.
  - 🍔 **주문하기**(카운터 앞): 그 가게 단계에서 파는 메뉴 + 사이드·음료를 골라 결제 → 준탁 셰프가 만들어 건네줘요 → 🪑 **테이블에 앉아 먹기**. 결제한 돈은 친구 가게 매출(오늘 매출 포함)이 돼요. 가격 = 기본가 × 그 가게 단계 배율(× 네온 간판). 하루 20번까지.
  - 👋 **사장님께 인사**: 하루에 친구마다 한 번 둘 다 +$10 (하루 10곳까지).
  - 📋 메뉴판 보기 · 🎵 주크박스(그 가게에 있으면) · 📒 방명록 쓰기.
  - 이모티콘(👋😋❤️👍🍔)으로 말풍선. **같은 가게에 있는 다른 친구도 실시간으로 보여요**(움직임·말풍선·들고 있는 음식).
- 내 가게(로비 🏠)도 걸어 다닐 수 있고, 최근 친구 주문 기록과 방명록을 봐요. 로비에 "오늘 친구 주문 n건"이 떠요.

## 어드민

로그인 화면·로비의 🔐 어드민 → 비밀번호(사천성과 같아요).

- **👥 플레이어 · 돈 주기**: 보유재산 **낮은 순**. 플레이어마다 돈 넣기·빼기(빠른 금액 $100/$500/$1,000), 새 코드 발급, 코드 정지. 위에서 모두에게 일괄 넣기·빼기.
- **📈 매출 종합**: 모든 유저의 하루 매출 합계(오늘 · 어제 · 7일 · 전체), 영업 횟수·손님 수, 최근 14일 날짜별 막대(누르면 그날 순위), 가게별 매출 순위. 실시간.
- 한 일은 `rooms/burger-log`에 남아요.

## 저장 (Firebase)

손모가지 조심!·사천성과 같은 Realtime Database(`gostop-7c4a2`)의 열려 있는 `rooms/` 아래에 `burger-` 이름으로 저장해요. **규칙은 바꿀 필요 없어요.**

| 경로 | 내용 |
|---|---|
| `rooms/burger-nicks/<닉네임>` | pid (닉네임 중복 확인) |
| `rooms/burger-acc-<코드>` | { pid, v } |
| `rooms/burger-players/<pid>` | 닉네임, 캐릭터, 현금, 가게 단계, 설비, 평점, 전적, 날짜별 매출 `sales/<YYYY-MM-DD>` = { rev, n, r } (120일), 친구, 방문 기록 |
| `rooms/burger-gb-<pid>` | 방명록 |
| `rooms/burger-pres-<가게 pid>/<방문자 pid>` | 지금 그 가게에 있는 사람 위치·말풍선 (나가면 지워져요) |
| `rooms/burger-log` | 어드민 작업 기록 |

주소 뒤에 `?local=1`을 붙이면 Firebase 없이 이 브라우저에만 저장해서 시험해 볼 수 있어요.
