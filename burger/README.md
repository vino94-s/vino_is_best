# 놀러오세요, 준탁의 어메리카 버거하우스

준탁 셰프와 버거 가게를 키우는 경영 게임이에요. 90초 영업 동안 손님 주문대로 버거·피자·감자튀김·콜라·생맥주를 만들어 팔고, 번 돈으로 가게를 확장해요.

## 입장

- **처음 왔어요**: 닉네임(2~10자 · 가게 이름이 돼요) + 내 캐릭터(벙참 캐릭터 13명) → 6자리 **입장 코드** 발급. 가입 선물 $100.
- **코드로 입장**: 이 기기에 코드가 기억돼서 다음엔 바로 들어가요. 잃어버리면 어드민에서 새 코드 발급.
- 매일 한국 시간 아침 6시 이후 첫 접속 때 출근 보너스 $50.

## 영업 (90초)

1. 아래빵 → 재료 → 위빵 순서로 쟁반에 버거를 만들어요 (재료 순서는 상관없어요).
2. 패티는 그릴에서 먼저 구워야 써요. 피자는 도우 → 소스 → 모차렐라 → 토핑 → 오븐(5초) → 꺼내기.
3. 다 만들면 그 손님을 눌러서 내줘요. 맞는 주문서는 초록색으로 반짝여요. 빨리 낼수록 팁이 커요.
4. 틀리면 평점 −, 손님이 기다리다 떠나도 평점 −. 평점이 높을수록 손님이 자주 와요.
5. 친구가 내 가게에 **손님으로** 와요(👫 표시) — 팁 2배!
6. 번 돈은 영업이 끝나면 바로 내 돈이 돼요. ✕로 중간에 접어도 그때까지 번 돈은 챙겨요.

## 가게 확장 5단계

| Lv | 가게 | 확장비 | 손님 자리 | 메뉴 값 |
|---|---|---|---|---|
| 1 | 🚚 푸드트럭 | 시작 | 2 | ×1 |
| 2 | 🏕️ 버거 스탠드 | $300 | 3 | ×1.15 (베이컨 메뉴) |
| 3 | 🍽️ 아메리칸 다이너 | $1,200 | 3 | ×1.3 (더블 패티) |
| 4 | 🇺🇸 어메리카 버거하우스 | $4,000 | 4 | ×1.5 |
| 5 | 🌟 버거하우스 본점 | $12,000 | 4 | ×1.8 |

단계마다 가게 그림(트럭 → 공원 스탠드 → 다이너 → 버거하우스 → 야경 본점)이 바뀌어요.

## 설비 10종

그릴 한 칸 더 $60 · 콜라 머신 $80 · 강화 버너 $120 · 튀김기 $150(Lv2) · 그릴 세 칸 $220(Lv2) · 생맥주 탭 $260(Lv2) · 주크박스 $300(Lv3) · 피자 오븐 $400(Lv3) · 알바생 $900(Lv3, 패티 자동 굽기) · 네온 간판 $1,500(Lv4, 가격 +20%). 값은 `index.html`의 `STAGES`, `UPG`에서 바꿔요.

## 친구

- 닉네임으로 추가하거나 랭킹에서 가게를 눌러 **친구 추가** → 서로 친구가 돼요.
- **놀러가기**: 친구 가게 그림·재산·매출을 보고, 하루에 친구마다 한 번 **🍔 버거 한 입** → 둘 다 +$10 (하루 10곳까지).
- **방명록**: 가게마다 60자 한마디. 최근 30개를 보여주고 40개가 넘으면 오래된 것부터 지워요. 내 가게 방명록은 로비 📒에서.

## 오픈 랭킹

- 💰 **보유재산** = 현금 + 가게 확장비 + 설비 값
- 📈 **오늘 매출** = 오늘(아침 6시 기준 영업일) 번 매출 합계. 실시간.

## 어드민

로그인 화면·로비의 🔐 어드민 → 비밀번호(사천성과 같아요).

- **👥 플레이어 · 돈 주기**: 보유재산 **낮은 순**. 플레이어마다 돈 넣기·빼기(빠른 금액 $100/$500/$1,000), 새 코드 발급, 코드 정지. 위에서 모두에게 일괄 넣기·빼기.
- **📈 매출 종합**: 모든 유저의 하루 매출 합계(오늘 · 어제 · 7일 · 전체), 영업 횟수·손님 수, 최근 14일 날짜별 막대(누르면 그날 순위), 가게별 매출 순위. 실시간.
- 한 일은 `rooms/burger-log`에 남아요.

## 저장 (Firebase)

손모가지 조심!·사천성과 같은 Realtime Database(`gostop-7c4a2`)의 열려 있는 `rooms/` 아래에 `burger-` 이름으로 저장해요. **규칙은 바꿀 필요 없어요.**

| 경로 | 내용 |
|---|---|
| `rooms/burger-nicks/<닉네임>` | pid (닉네임 중복 확인) |
| `rooms/burger-acc-<코드>` | { pid, v } |
| `rooms/burger-players/<pid>` | 닉네임, 캐릭터, 현금, 가게 단계, 설비, 평점, 전적, 날짜별 매출 `sales/<YYYY-MM-DD>` = { rev, n, r } (120일), 친구, 방문 기록 |
| `rooms/burger-gb-<pid>` | 방명록 |
| `rooms/burger-log` | 어드민 작업 기록 |

주소 뒤에 `?local=1`을 붙이면 Firebase 없이 이 브라우저에만 저장해서 시험해 볼 수 있어요.
