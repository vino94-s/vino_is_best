# 내가바로 윷잡이!

깨굴, 용왕, 엄지, 영준, 햇살, 묭라닥, 고란, 여니, 비노, 만두, 준탁. 열한 캐릭터 중 하나를 골라 내 말 4개로 윷판을 돕니다. 친구랑은 1:1이나 2:2 팀전으로 붙을 수 있어요.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치할 것은 없습니다.

1. 닉네임을 넣고 **봇이랑 한 판** 또는 **친구랑 한 판**을 고르세요.
2. 캐릭터를 고르면 그 캐릭터가 내 말 4개가 돼요.
3. **던지기 버튼을 꾹 누르고 있다가 놓으면** 윷을 던져요. 누르는 동안 파워 게이지 바늘이 왔다 갔다 해요.
   - 황금 구간: 도·개가 나왔을 때 30% 확률로 한 번 더 굴려 줘요.
   - 빨간 끝(낙 위험): 45% 확률로 윷이 멍석 밖으로 튀어 그 던지기가 무효(낙)가 돼요.
4. 끗수 칩을 고르고, 반짝이는 말이나 판 위의 점선 목적지를 누르면 움직여요.

- 상대 말을 잡으면 출발 전으로 돌려보내고 한 번 더 던져요.
- 내 말끼리 같은 칸에 멈추면 업혀서 같이 움직여요.
- 모·뒷모 모서리나 가운데 방에 딱 멈추면 다음 차례에 지름길로 가요.
- 참먹이(출발점)를 지나가야 나가요. 참먹이에 딱 멈추면 다음 차례에 아무 끗수로나 나가요.
- 말 4개를 먼저 모두 내보내면 이겨요.

## 친구 대결 (방 코드)

1. 한 명이 **1:1** 또는 **2:2 팀전**을 고르고 **방 만들기**를 누르면 4자리 방 코드가 나와요. **초대 문구 복사**로 친구에게 보내세요.
2. 친구는 **코드로 입장**에 코드를 넣거나 받은 링크를 열면 같은 방에 들어와요.
3. 모두 캐릭터를 고르고(전부 다른 캐릭터) **준비 완료**를 누르면 시작해요.
4. 판마다 먼저 던지는 쪽이 번갈아 바뀌어요. 끝나고 모두 **한 판 더**를 누르면 이어서 해요.

### 2:2 팀전

- 4명까지 들어와요. 방장은 대기실에서 방식을 바꾸거나, **팀 섞기**로 팀을 다시 짜거나, **빈자리 봇으로 채우기**로 3명·2명이서도 팀전을 할 수 있어요.
- 팀이 말 4개를 함께 써요. 2개는 첫째 팀원, 2개는 둘째 팀원 캐릭터로 보이지만 던진 사람이 팀 말 아무거나 움직일 수 있어요.
- 던지는 순서: 적팀 1번 → 청팀 1번 → 적팀 2번 → 청팀 2번.
- 상대 말을 잡으면 그 말을 잡은 사람의 캐릭터가 나와서 조롱해요.
- 방장이 가운데서 모두의 수를 이어 줘요. 방장이 나가면 경기가 끝나요.

GitHub Pages에서는 PeerJS로 브라우저끼리 직접 연결돼요. claude.ai 아티팩트에서 열면 아티팩트의 방 기능으로 연결돼요.

## 오픈 랭킹

봇 대전 랭킹(승수, 승률, 최단 승리 차례)과 친구 대전 랭킹이 따로 있어요. 친구 대전은 개인 순위(1:1과 팀전 합산, 팀전 전적 따로 표시), `닉네임 vs 닉네임`·`닉네임 & 닉네임 vs 닉네임 & 닉네임` 맞대결 전적, 최근 대결을 보여 줘요. 봇 자리는 개인 순위에서 빠져요.

GitHub Pages에서 모두가 같은 랭킹을 보려면 `ranking-apps-script.gs`를 구글 시트의 Apps Script에 붙여 웹 앱으로 배포하고, 그 주소를 `index.html`의 `RANK_API`에 넣어 주세요. 비어 있으면 플레이한 브라우저에만 저장돼요. claude.ai 아티팩트에서는 아티팩트 공유 DB에 바로 저장돼요.
